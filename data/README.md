

\# Origen y documentación de los datos



Este directorio contiene los archivos utilizados para las pruebas y evaluación del proyecto.



\## Fuentes de datos



Los datos utilizados en el proyecto tienen los siguientes orígenes:



\### 1. Catálogo y preguntas frecuentes

Son datos ficticios creados para el proyecto. Se encuentran definidos en `app/seed.py`.



\### 2. Casos de desarrollo

El conjunto de 50 casos utilizados durante el desarrollo y evaluación se encuentra en `scripts/evaluar\_llm.py`.



\### 3. Casos de prueba ciega

El archivo `data/casos\_prueba\_ciega.json` contiene 30 casos redactados por Claude y revisados por el equipo de trabajo.



\## Consideraciones



Los datos se utilizan con fines académicos y de evaluación del comportamiento del asistente.



Los casos de desarrollo y los casos de prueba ciega tienen propósitos diferentes y deben mantenerse separados durante el proceso de evaluación.
